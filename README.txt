# JHAROHAR - DICE Prototype

A starter Streamlit web app for showcasing Jharkhand's tribal art and artists.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run: `python -m pip install -r requirements.txt`
4. Run: `streamlit run app.py`
5. Open the local address shown in the terminal.

## Publish online
For a public shareable link, push these files to a GitHub repository and deploy the repository with Streamlit Community Cloud. Choose `app.py` as the app file and `requirements.txt` will install dependencies.

## Important prototype limitations
- Artist registrations are stored only in the current app session and are not permanent.
- Do not enter real personal data yet.
- Gallery content is placeholder/sample content. Verify all cultural descriptions with artists and communities before publishing.
- QR codes are demo identifiers, not permanent public artwork URLs yet.
- The interface currently includes English and Hindi labels. Regional language content needs translation and review by fluent speakers.
- This is a web app that works in a phone browser, not a native Android APK.
